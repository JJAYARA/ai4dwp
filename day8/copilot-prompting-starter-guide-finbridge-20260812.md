# Copilot Prompting Starter Guide (FinBridge)

Audience: Non-technical office staff
Purpose: Help you get useful results from Microsoft 365 Copilot in daily work

## Start Here: A Simple Prompt Formula

Use this 4-part formula every time:

**Ask + Context + Format + Check**

- Ask: What do you want Copilot to do?
- Context: What is this for, and who is it for?
- Format: How should the answer be structured?
- Check: What should Copilot double-check before finishing?

Easy template to copy:

"Please **[ask]** using **[context]**. Return it as **[format]**. **[check]** before finalizing."

Quick example:

"Please draft a follow-up email to a supplier using the notes from today’s meeting. Return it as a short email with a clear subject and 3 bullet actions. Check that dates and owner names are included before finalizing."

## Outlook: Real Prompts You Can Use Today

### 1) Summarize a busy inbox
"Review my unread emails from the last 2 business days and summarize the top 5 items I need to act on. For each item, include sender, deadline (if mentioned), and a one-line recommended next step. Return as a numbered list in priority order."

### 2) Draft a clear follow-up email
"Draft a polite follow-up to Alex Morgan about the missing approval for the Q3 vendor onboarding form. Keep the tone professional and friendly. Include a clear request for response by Friday 3:00 PM and suggest two available meeting slots next week. Keep it under 140 words."

### 3) Prepare for a meeting from email history
"Using my recent email conversation with the Finance Operations team about invoice issues, create a short meeting prep note with: what we already agreed, open questions, possible risks, and decisions needed today. Return it in 4 short sections with bullet points."

## Word: Real Prompts You Can Use Today

### 1) Turn rough notes into a polished draft
"Using the notes in this document, create a one-page project update for senior managers. Keep plain business English, avoid jargon, and structure it as: Summary, Progress, Risks, Next 2 Weeks. Add a short action list at the end."

### 2) Rewrite for a different audience
"Rewrite this policy update so it is easy for all office staff to understand. Keep meaning unchanged, shorten long sentences, and replace technical terms with plain alternatives where possible. Add a quick 'What you need to do' section with 3 bullets."

### 3) Tighten and proofread
"Edit this draft to be more concise and confident. Remove repetition, improve flow, and correct grammar. Keep the tone friendly and professional. Then provide a short change summary listing the 5 most important edits you made."

## Excel: Real Prompts You Can Use Today

### 1) Explain trends in data
"Look at the 'Monthly Spend' table in this workbook and tell me what changed over the last 6 months. Show the 3 biggest cost increases, any unusual jumps, and possible reasons in plain language. End with 3 practical actions I can take."

### 2) Build useful formulas with explanation
"In the 'Tickets' sheet, create formulas for: (1) how many days each ticket has been open, (2) status labels for due dates (On Track / At Risk / Breached), and (3) a simple priority score using the impact and urgency columns. Explain each formula in plain English and tell me exactly where to paste it."

### 3) Prepare a quick leadership view
"Create a simple summary from the 'Service Requests' data showing: total requests, percent resolved, average days to resolve, and the top 5 request categories. Then suggest easy-to-read chart types for each and explain each choice in one short sentence."

## Data Safety Habit (From Day 1)

You can use Copilot confidently for daily work. Before you prompt, do the same quick Day 1 data-safety check:

- Do not paste confidential client data into external AI tools.
- Use approved FinBridge tools and approved data locations only.
- If you are unsure whether data is confidential, pause and ask first.

Good practice:

- Replace personal names, account numbers, and client identifiers with placeholders when possible.
- Ask Copilot to work from files already in approved Microsoft 365 locations instead of copying sensitive text into unapproved tools.

## Prompt Upgrade Tips (Fast Wins)

If a result is weak, improve the prompt in one line:

- Add audience: "for a senior manager" / "for new starters"
- Add scope: "use last 30 days" / "focus on unresolved items only"
- Add result format: "table with 4 columns" / "email under 120 words"
- Add a final check: "flag missing dates" / "state assumptions clearly"

## One-Minute Prompt Checklist

Before sending a prompt, ask:

1. Is my Ask clear?
2. Did I include enough Context?
3. Did I specify the output Format?
4. Did I add a Check for quality or completeness?
5. Is my data safe and appropriate to use?

Using this guide, you do not need to be technical. You just need clear intent, enough context, and safe data habits.
